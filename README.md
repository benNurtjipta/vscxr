# vscrx

Are you lazy as i am? Don't want to press cmd+shift+p for command palette in VS Code?
Looking for `{}` or `||` on your keyboard?

This extension connects to [vscrx](https://github.com/benNurtjipta/vscrx) Android app that lets you execute commands remotely.

[github page](https://github.com/benNurtjipta/vscxr)
